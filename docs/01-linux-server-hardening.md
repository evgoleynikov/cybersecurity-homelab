# 01. Linux Server Deployment & Hardening

## Цель работы

Развернуть Linux-сервер в домашней виртуальной среде,
настроить безопасное удалённое администрирование,
сетевой экран и веб-сервер.

## Используемые технологии

- Ubuntu Server 24.04 LTS
- TerraMaster VMs
- OpenSSH
- UFW
- Nginx

## Этапы работы

1. Создание виртуальной машины
2. Установка Ubuntu Server
3. Настройка сетевого подключения
4. Настройка SSH-аутентификации по ключам
5. Отключение парольной аутентификации
6. Настройка UFW
7. Установка и проверка Nginx

## Результат

Linux-сервер развёрнут, SSH-доступ защищён ключами,
входящие подключения ограничены правилами UFW,
Nginx успешно обслуживает HTTP-запросы.
